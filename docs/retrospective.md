# 公开版复盘

## 已验证的改进

- 私有参考页不适合作为公开测试数据。公开版使用自制的纯色 PNG 测试图片，仍检查原图字节实际嵌入 PPTX，并保留可编辑图注。四项渲染测试通过，合成示例的样稿和整稿均生成成功。
- 测试需覆盖用户审阅边界。合成示例实际验证了无确认时不能生成整稿，来源文件或页面方案变更后确认失效；仅测试工具提供显式模拟确认，正式任务仍需真实用户确认。
- 可发布文件与本机工作资料容易混在一起。公开版使用独立 Git 历史，只包含源码、通用风格规则、合成样例及检查工具；发布包验证会排除依赖、原始文档和运行产物。

## 待验证和改进

- 当前渲染适配器依赖的 `@oai/artifact-tool` 为专有软件，开发环境的许可存在使用限制。可研究支持公开许可的渲染后端；该后端尚未实现。
- 此前在目标应用中观察到图表自动纵轴刻度与渲染预览不同。可增加显式刻度并在目标应用复验；目前数据标签保持独立检查。
- 公开版将六种风格的标识改为通用名称。此前使用旧标识保存的个人项目方案，需要将 `style` 调整为当前目录中的对应标识后再使用。
