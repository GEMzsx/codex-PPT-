# 项目知识与联网补充

项目知识在目标项目 `.ppt-assistant/` 内建立，依据用户指定的论文、文档、数据和图片。跨任务可复用通用排版与制作规则；本项目的实验事实、解释和科学资料保留项目归属及来源。

导入后使用运行时给出的稳定来源 ID。知识条目保留原文定位、适用条件与引用；区分文献内容、本项目结果、假设和缺口。增补或替换材料后查看当前状态，重新整理受影响的知识与页面。

联网用于补充背景、术语或文献。实际读取支持所用知识的一手来源，记录链接、出版或获取信息，注明补充了什么及为何使用。项目研究结果以当前材料为依据，文献结果归于对应文献。

补充知识清单应覆盖：知识点、来源、使用原因、页面 ID；尚未使用的内容标注其状态。样稿交付附当阶段清单，整稿交付更新页面对应关系。用户需能看出哪些内容来自提供的材料、哪些由联网增加。

知识、补充清单与方案通过[运行接口](runtime.md)登记。目录和 JSON 格式服从实际命令帮助；事实与来源完整后再进入内容策划。
