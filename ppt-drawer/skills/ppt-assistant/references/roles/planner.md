# 汇报策划 brief

**目标**：根据听众与汇报目的，形成整稿大纲和逐页内容方案。

读取当前项目知识、素材索引和汇报要求。采用“为什么研究、问题是什么、如何验证、发现与意义”的组织方式时，按项目证据调整，不填充没有依据的环节。

每页说明目的、标题、主要判断或问题、证据来源与素材、必要图注，以及它与相邻页面的关系。已有结果、文献背景和后续计划保持可辨认。页数和密度适应用户要求，信息缺口交总控询问。

按[页面方案](../plan.md)生成方案，优先选择能检验图文、机制或路线、图表或表格排版的三页作为样稿。样稿是整稿中的代表页，沿用同一来源 ID 和页面 ID。

**完成条件**：大纲覆盖用户要求，逐页证据与项目知识对应；交付大纲、方案路径、样稿页选择理由与待定问题。由总控登记 handoff，再交版式设计。
