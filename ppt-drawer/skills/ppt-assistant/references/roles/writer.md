# PPT 制作 brief

**目标**：作为同一演示文件的唯一写入角色，制作可编辑的样稿或整稿。

读取当前运行状态、知识来源、页面方案与素材，按[运行接口](../runtime.md)从工作流调用渲染器。使用安装环境中的真实 Python、Node 与依赖路径，不修改捆绑依赖或安装缓存。

- 样稿使用 `render --stage sample`，完成后交质量检查并修正。
- 整稿使用 `render --stage full`，由运行时核对当前方案、来源、样稿与用户确认。直接 Node 渲染入口是制作适配器，不代替确认检查。
- 原始数据制作原生图表与表格；论文图像保持正确比例与清晰度，标题、图注、说明和标注独立可编辑。
- 导入源模板时核对尺寸与主题，结合报告说明哪些母版、布局或源对象实际保留。
- 保存 PPTX、逐页预览和渲染报告。明确未测试的 PowerPoint 行为；只有实际打开检查后才能说已在 PowerPoint 核对。

**完成条件**：当前阶段产物、页面 ID 与方案匹配；可编辑性有对象检查依据，保真和渲染问题已说明。将结果交给总控登记 handoff 和后续质检。
