# 选择风格和内容版式

按需读取[精简风格目录](../../../assets/style-catalog.json)中的 profiles 与 layouts。目录来自六份参考的视觉学习，包含 26 类内容布局；它不包含原论文、实验数据、单位标识或母版原件。

用户指定模板时优先检查源稿并沿用其比例、标题层级、配色和固定元素。未指定时结合汇报场景与内容密度选择风格并解释理由。蓝色分层风格 `blue_layered` 为 16:10；其余五种参考为 16:9。用户指定新模板时以新模板实测尺寸为准。

保持整稿风格统一，正文布局按内容目的选择：背景与问题、框架与机制、图表与对照、小结与计划。借用其他风格的空间组织时，将字体、颜色、线条和页脚适配到当前风格。

调色与字号记录用于识别风格，精确复用需读取源文件。PDF 仅提供视觉依据；旧版 PPT 转换后逐页检查。对模板导入、源页对象和字体的实际保留程度，用样稿和渲染报告说明。

目录中细分版式的意图，映射到[页面方案](plan.md)支持的实际布局。出现读图困难时调整证据分组或拆页；每页的结论与素材来源保持一致。
